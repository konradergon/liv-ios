# Archive

History, not guidance. These are the specs, studies, plans and mockups
Liv was built from, up to 30 September 2026. Many describe older apps and
older plans, say `lotus_*` for `liv_*`, and cite a Mac shell that no
longer exists.

Code comments still cite some of them by name (`ios.md §6`,
`core.md §2`, `rust-owns-the-mechanisms.md`); they are all here.

What is true now is in `HANDOUT.md`, `design/what-liv-is-for.md`,
`design/how-its-built.md` and `design/changelog.md`.
