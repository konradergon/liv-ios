Phase 3 mockup — “In notes” (design/tasks-study.md)

The Tasks view gains one section: every open - [ ] line from live notes, each carrying its source. Checking a row edits the note’s text — the same write the editor’s checkbox makes. Tapping the source chip opens the note as a desk tab.

Entity tasks keep everything they have today (status ring, due swipes, chips). Note-lines deliberately have none of that — they are text, and the section says so by shape: square checkbox, no ring, no status.
